# Mahi's Cafe - Restaurant Menu Ordering System

## About My Project
I created this project using Python. It is a simple restaurant ordering system for Mahi's Cafe. Customers can select items from the menu, order multiple items, and check the total amount.

## Problem Statement
Create a simple restaurant ordering system where customers can view the menu, select food items, order more than one item, and calculate the total bill. The program should also check whether the entered item is available on the menu.

## Menu
- Pizza - Rs. 150
- Burger - Rs. 100
- Coffe - Rs. 120
- Chai - Rs. 40
- Dosa - Rs. 50

## What I Used
- Python Dictionary
- Variables
- `input()` and `print()`
- `if-else` statements
- `while` loop
- `break` statement
- `upper()` string method
- Arithmetic operators

## How My Project Works
1. First, it displays the welcome message and menu.
2. It asks the customer to enter an item name.
3. If the item is available, its price is added to the total.
4. If the item is not available, it displays a message.
5. It asks whether the customer wants to order another item.
6. Finally, it displays the total amount to pay.

## Problems I Faced
- I faced a problem when checking whether the entered item was available on the menu.
- I learned that uppercase and lowercase letters can affect string matching.
- I used a `while` loop to allow customers to order multiple items.
- I learned how to add the price of each selected item to the total bill.

## What I Learned
While making this project, I practised Python dictionaries, loops, conditional statements, user input, string methods, and calculating the total bill.

## How to Run
1. Save the code in `CafeMenu.py`.
2. Open the terminal in the project folder.
3. Run the following command:
